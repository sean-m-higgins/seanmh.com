The canonical switcher kit = two byte-identical files on content plus the three portfolio branches:

  • src/components/VersionSwitcher.astro — the dial. It handles pageswap/pagereveal, touch expansion, aria-expanded, Escape-to-close, focus restoration, and a non-interactive current-version item.
  • src/styles/transitions.css — @view-transition { navigation: auto }, the sean-name/universe-dial morph groups, per-version flavor (CRT power-on for terminal, 3D tilt for card, rise for scroll), reduced-motion off-switch.

Per-version wiring (not in the kit): each layout imports transitions.css and renders <VersionSwitcher current="…" />; each version's identity headline carries vt-sean-name, and its intro-animated container carries vt-skip-intro.

Cookie nuance (already handled): worker.js and dev-proxy.mjs only set the pv cookie when Sec-Fetch-Dest: document (or Accept includes text/html). This stops a stale in-flight asset request from the old version overwriting a just-switched cookie. Preserve this if you touch cookie logic.
Kit-sync rule: edit on content, then copy/cherry-pick to version/a-scroll, version/b-card, and version/c-terminal. The July 25 accessibility commits are verified byte-identical: component SHA-256 de3705e…, transition CSS SHA-256 eed3588….
