seanmh.com — Taking the Multiverse to the Next Level

June 2026 · Current state: Astro site, 3 versions on branches (version/a-scroll, version/b-card, version/c-terminal), shared content branch, Cloudflare Worker randomly assigns versions with a switcher.

Thesis: The branch-per-version architecture is already the most interesting thing about this site. Instead of bolting on generic animation (the motionsites.ai route), make the multiverse itself the spectacle — then add one signature interactive piece and a layer that makes the site feel alive.

Tier 1 — Amplify the Multiverse most novel

1. The Self-Redesigning Website novelwow

A scheduled AI agent (Claude Code cloud routine / GitHub Action) generates a brand-new Version D on a cadence — say monthly — as a PR on a new version/d-* branch. You approve, it deploys, and the worker adds it to rotation. Past generations live in a browsable "Hall of Versions" gallery with the prompt + date that created each one.

Pitch line on the site: "This website redesigns itself. You're looking at generation #7." Nobody else has this. It also showcases exactly the AI-partner workflow you care about.

2. Cinematic Version Switching wow

Replace the plain redirect switcher with a portal transition: a shared "Sean identity card" element morphs between layouts (View Transitions API works cross-document on same-origin — perfect fit since the worker serves all versions from one domain). The switcher becomes a "universe dial" UI present in every version.

3. Public A/B Scoreboard low effort

Log version assignments and switch-aways in Cloudflare Analytics Engine (or KV counters). Publish a live "Which universe is winning?" page — engagement per version, switch rates. Turns your infrastructure into content and shows product-thinking, not just code.

Tier 2 — One Signature Interactive Piece visitor wow

4. The Nexus — a 3D entry world

A lightweight Three.js scene where the versions are physical doors/portals floating in space; walk or drag to one to enter it. Inspired by Bruno Simon's drivable portfolio (Awwwards Site of the Month, Jan 2026) but scoped small: one scene, three portals, <1MB. Could itself live on a branch as version/nexus — the meta-version that contains the others.

5. Make the Terminal Version Real novel

  • Working commands: ls projects, cat resume.md, git log (real repo history), tab-completion, history.
  • ask <question> — Claude-powered answers grounded in your resume/projects, streamed into the terminal via a Worker.
  • Stretch: ssh seanmh.com serves an actual SSH portfolio (Charm's wish library, runs on a $4 VPS). Massive engineer cred.

Tier 3 — Make It Feel Alive quick wins

6. Live "Now" Layer

A small shared component (lives on the content branch, so all versions get it): latest GitHub commit, currently-playing on Spotify, your local time. One Worker endpoint, cached, free tier.

7. Visitor Trace

A tasteful collaborative artifact — e.g. a pixel wall or signature constellation backed by Workers KV/D1. Each visitor leaves one mark; the site visibly accumulates history.
