The only project plan. Consolidated and repository-audited August 27, 2026.

Rule: unfinished work belongs here. A feature-specific plan may exist only while actively executing that item; when the work ships, its durable architecture and operating knowledge must be verified in the wiki before the temporary plan is deleted.

Architecture and operating decisions

AreaDecision to preserve
Homepage routingVERSIONS contains a-scroll, b-card, and c-terminal; a-scroll is the only anonymous default. Nexus and both games belong in manual-only ROUTABLE.
Path-owned contentBlueprint owns /systems/*. Travel will own /travel/*. Resolve path apps and site-wide control files before version cookies, strip the public prefix upstream, rewrite same-origin redirects, and never let a path app alter pv.
Shared contentThe content branch is canonical for shared profile facts and the switcher kit. a-scroll's expanded content schema is a documented manual-port exception.
Progressive enhancementNavigation and meaningful content must survive unsupported View Transitions, reduced motion, disabled JavaScript, denied storage, and unavailable WebGL.
IndexingThe clean apex profile is the canonical identity. Similar profile presentations may consolidate to it; materially distinct experiences must not claim the résumé homepage as equivalent. Direct Pages origins are secondary and should be noindex without leaking that signal through the Worker.
Release evidenceA commit is not “shipped.” Record checks, deployment identifiers, live smoke results, and rollback targets before marking production work complete.
ToolchainUse Node 22.12 or newer everywhere. Pin deployment tooling and enforce the same version in CI.

P0 — correctness, resilience, and release safety

  1. P0Replace concurrency-unsafe KV mutation and rate limiting. Move both leaderboard updates away from shared KV read/modify/write values to a Durable Object or D1 transaction. Move paid-path/API rate limiting to a Durable Object or Cloudflare rate-limiting binding. Until migration, do not silently allow a paid Anthropic request when the limiter write fails. Preserve the Halfpipe and Counter request/response contracts, separate boards/namespaces, ranking, top-ten truncation, validation, and no-KV degradation.

    Done when: simultaneous accepted submissions cannot overwrite one another, limiter failure fails safely on the paid path, and concurrency/rate-limit tests pass for both boards and /api/ask.

  2. P0Fix Halfpipe state and lifecycle bugs, then establish tests. Give riding/pumping an explicit render state instead of checking airborne grabbing. Clear held keyboard and touch controls on blur, pagehide, hidden visibilitychange, pointer cancellation, and teardown. Add pure tests for riding/pumping, launch/landing, grab reset, trick chains, scoring, persisted-data recovery, focus loss, and the client/server plausibility contract.

    Done when: pumping visibly crouches, stale grab state cannot affect a landing/riding pose, controls never remain held after focus loss, and a repeatable Halfpipe test suite runs in CI.

  3. P0Make Nexus fail safely. Construct the real THREE.WebGLRenderer once inside try/catch instead of relying on a throwaway capability probe. If construction fails, reveal the same accessible fallback used for no WebGL. Handle webglcontextlost by stopping animation and revealing fallback navigation. Pause rendering while hidden; under reduced motion, render on demand rather than running a full continuous loop.

    Done when: probe success followed by renderer failure and a simulated context loss both leave usable HTML navigation, and hidden/reduced-motion states do not waste a full animation loop.

  4. P0Add end-to-end deadlines and one authoritative /api/ask implementation. Put an explicit abort deadline around the Worker upstream request and stream, the Terminal Pages function, and the browser client. Cancel abandoned streams and return a consistent retryable error. Then either extract one shared tested handler or make one endpoint authoritative and proxy the other; eliminate drift in validation, model selection, headers, rate limiting, and stream handling. Serialize or deliberately reject concurrent interactive ask commands so output cannot interleave.

    Done when: stalled upstreams terminate predictably, client output remains ordered, both deployment paths share the same behavior, and tests cover validation, streaming, timeout, rate limiting, and upstream errors.

  5. P0Complete the technical SEO release contract. Re-audit production first because the August 17 live observations may have changed. Then close the source-to-production gap, normalize HTTP/www to the HTTPS apex with a one-hop method-preserving 308, strictly validate v/pv, apply URL-level robots policy, add real b-card/c-terminal 404s and explicit error metadata everywhere, strip origin-only robots headers before deindexing Pages origins, and keep control files deterministic.

    Done when: the response matrix below has Worker tests and two independent live smoke passes; twenty anonymous cache-busted homepage requests serve a-scroll; every unknown content path is a real 404; explicit distinct-experience URLs and all API responses are noindex; and the clean apex never inherits origin noindex.

  6. P0Establish CI and reproducible tooling. Add workflows for all Astro checks/builds, main Worker tests, Counter tests, new Halfpipe tests, Terminal TypeScript checks, shared-content verification, and the eventual SEO/route-contract checks. Make the shared check work from Git refs/checkouts rather than assuming sibling worktrees. Set every package engine to >=22.12.0, add the environment's chosen version-manager config, pin Wrangler locally, and commit the lockfile.

    Done when: a clean checkout can run the full matrix with pinned Node/deployment tooling and no developer-specific worktree layout.

  7. P0Finish release-blocking device and accessibility QA. Cover Chrome, Edge, Safari, and Firefox desktop plus iOS Safari and Android Chrome. Verify cross-document switching and fallback links; a-scroll pinning, anchors, Lenis, themes, scroll restoration, fine-pointer/coarse-pointer/multitouch behavior; Nexus carousel, focus, drag, tap, tilt, reduced motion, no-JS, no-WebGL; Halfpipe and Counter keyboard/touch/audio/restart/focus loss; and Blueprint path behavior.   • Highlight explicit visited-country declarations and trip anchors. Dublin may appear in a route without marking Ireland visited. Selecting a country/trip reveals dates, summary, cover, and links to overview, itinerary, and photos.

  • Required pages/files: /travel/, Norway overview, itinerary, photos, sanitized downloadable HTML, and generated downloadable PDF.
  • The itinerary is the historical pre-trip plan; the globe is the confirmed actual route. Never substitute planned stops for observed travel. Keep unpublished route data out until Sean confirms it.

  • Provide complete server-rendered navigation and a generated static SVG/poster map for JavaScript/WebGL failure. Respect reduced motion, pause while hidden, cap DPR, and load Three.js after the usable HTML shell.
